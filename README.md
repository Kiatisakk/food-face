# หน้าฉันกินได้

โยนรูปหน้าลงไป แล้วมันจะหั่นเป็นพิกเซล เปลี่ยนแต่ละช่องเป็นอีโมจิอาหารที่สีใกล้ที่สุด พร้อมใบเสร็จที่ไม่มีประโยชน์

เป็นเว็บแบบ HTML + CSS + JS ธรรมดา ไม่ต้อง build

## รัน

```sh
npm start          # เปิด http://localhost:5173
```

หรือดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ตรง ๆ ก็ได้

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โครงหน้าเว็บ |
| `style.css` | หน้าตา (สลับธีมมืด/สว่างตามเครื่อง) |
| `menu.js` | รายการอาหาร: อีโมจิ, ชื่อ, ราคา, kcal — แก้ตรงนี้เพื่อเพิ่มเมนู |
| `app.js` | หั่นภาพ จับคู่สี วาดอีโมจิ ทำใบเสร็จ บันทึก PNG |
